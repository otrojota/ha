SATÉLITE WEB EN RASPBERRY PI
============================

Hardware objetivo:

- Raspberry Pi 5 de 8 GB.
- Raspberry Pi OS Lite de 64 bits.
- Pantalla táctil oficial de 7 pulgadas.
- Speakerphone USB con AEC.

La Raspberry no ejecuta el backend del asistente. Chromium abre la aplicación
publicada por el servidor y usa las APIs del navegador para el micrófono y el
TTS. El único daemon propio del satélite es el cliente oficial Sendspin para
Music Assistant.

Preparación:

1. Instala Raspberry Pi OS Lite de 64 bits.
2. En raspi-config selecciona Labwc y Desktop Autologin.
3. Instala el release de `releases/satellite`.
4. Edita `/etc/ha/satellite.env` y define `SERVER_URL`, por ejemplo:

       SERVER_URL=https://ha-server

5. Reinicia la Raspberry.

El display debe cargar desde esa URL. La primera interacción del navegador
puede ser necesaria para conceder permiso de micrófono. El script de kiosco
habilita la URL configurada como contexto seguro cuando el servidor usa HTTP en
la LAN; HTTPS sigue siendo preferible en producción.

Diagnóstico:

    /opt/ha/current/health-check.sh
    sudo systemctl status ha-satellite --no-pager
    sudo journalctl -u ha-satellite -f

La selección de micrófono, canal y salida TTS se realiza dentro del display.
La salida de música se elige en Sendspin o Music Assistant y no se mezcla con
la configuración TTS del navegador.
