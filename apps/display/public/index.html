Spotify Connect

Conecta una cuenta Spotify Premium para encontrar los dispositivos disponibles en Spotify Connect.

Cómo obtener el Client ID de Spotify
  1. En un computador o teléfono, abre Spotify for Developers e inicia sesión con tu cuenta Spotify Premium.
  2. Presiona Create app, escribe un nombre y una descripción, y selecciona Web API entre las APIs que utilizará.
  3. En la aplicación creada, abre Settings y agrega como Redirect URI exactamente la dirección que aparece debajo en esta pantalla.
  4. Guarda los cambios, vuelve a la página principal de la aplicación y copia su Client ID. No copies ni compartas el Client Secret.
  5. Pega el Client ID aquí, presiona Guardar y después Conectar Spotify.

En Development Mode, Spotify limita cada aplicación a cinco usuarios autorizados. Los usuarios adicionales deben agregarse desde Settings → Users Management.

Registra exactamente esta Redirect URI en tu aplicación de Spotify. No se necesita Client Secret.

Spotify sólo informa equipos disponibles recientemente para la cuenta conectada. Si un equipo aparece en el teléfono pero no aquí, selecciónalo desde Conectar a un dispositivo, inicia una reproducción en ese equipo y, mientras continúa reproduciendo, vuelve a buscar desde esta pantalla.
