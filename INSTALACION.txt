INSTALACIÓN Y ACTUALIZACIÓN
===========================

Servidor
--------

Construir el artefacto:

    ./releases/server/package.sh

El bootstrap y los detalles de plataforma están documentados en
`releases/server/README.md`. La instalación habilita:

    ha-containers.service
    ha-music-gateway.service
    ha-server.service

Verificación:

    /opt/ha/current/health-check.sh
    sudo systemctl status ha-containers ha-music-gateway ha-server --no-pager

Satélite web
------------

Construir el artefacto:

    ./releases/satellite/package.sh

Instalar en Raspberry Pi OS Lite de 64 bits:

    curl -fsSL https://raw.githubusercontent.com/otrojota/ha/main/releases/satellite/install.sh | sudo sh

Después, configura `/etc/ha/satellite.env`:

    SERVER_URL=https://ha-server

El release habilita solamente `ha-satellite.service`, que ejecuta Sendspin.
Chromium Kiosk se inicia desde Labwc y descarga la aplicación desde
`SERVER_URL`; no existe un servidor web local en la Raspberry.

Verificación:

    /opt/ha/current/health-check.sh
    sudo systemctl status ha-satellite --no-pager
    sudo journalctl -u ha-satellite -f
